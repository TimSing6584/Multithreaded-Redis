# Benchmark: real Redis vs Redis-k02 single-thread vs Redis-k02 multithread

Generated by `benchmark/run.sh` on 2026-11-17 14:48 (took 12 min).

- **Machine:** 11th Gen Intel(R) Core(TM) i5-1135G7 @ 2.40GHz, 8 CPUs, Linux 6.18.58.1-microsoft-standard-WSL2
- **Real Redis 7.0.15** on port 5000, started as `redis-server --port 5000 --save "" --appendonly no` (no persistence, like Redis-k02).
- **Redis-k02** on port 4000: single-thread, and multithread (io handlers=4, workers=4). MaxKeys = 10000000.
- `PORT` in the commands is 5000 for real Redis and 4000 for Redis-k02.
- Each test ran **once** per server, each time on a freshly started server (empty keyspace), so expect a few % noise.
- redis-benchmark ran on the same machine, so it competes with the server for CPU.
- **Bold** = best in the row (highest requests/sec, lowest latency).

## 6. Heavy command: SMEMBERS on ~400-member sets
